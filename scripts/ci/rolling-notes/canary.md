# Bobine — Canary (build automatique)

> **Canal Canary (rolling).** Pre-release construite automatiquement depuis le tout dernier commit de `main`, sans curation, republiée **en place** sur le tag mobile `canary` (jamais un nouveau tag par itération). Une version stable équivalente ou plus récente la remplace toujours automatiquement.

Réservée aux utilisateurs ayant activé le canal Canary (Réglages → Mises à jour). Pour un accès anticipé moins volatil, voir le [canal Bêta](https://github.com/FantasmaGlad/Bobine/releases/tag/beta) (lots curés, publication manuelle).

**Basé sur** commit `__COMMIT__` · version à venir `__VERSION__`
