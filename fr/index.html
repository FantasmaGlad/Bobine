Dépôt APT Officiel Bobine

Installation et mises à jour logicielles pour Debian 12 / 13 et Ubuntu 22.04 / 24.04 LTS via apt. Dépôt binaire x86-64 signé cryptographiquement par GPG avec prise en charge des canaux Stable et Bêta.

Dépôt opérationnel Debian 12 / 13 Ubuntu 22.04 / 24.04 LTS Architecture amd64 Signature RSA 4096

Installation en 3 étapes

1.

Trousseau de clés GPG officiel

Enregistrez la clé publique du dépôt dans /etc/apt/keyrings/ pour vérifier l'authenticité des paquets :

Terminal (Bash)
curl -fsSL https://apt.bobine.fit/bobine.gpg | sudo gpg --dearmor -o /etc/apt/keyrings/bobine.gpg
2.

Déclaration de la source de paquets APT

Ajoutez le dépôt officiel à la liste de vos sources logicielles (canal stable par défaut) :

/etc/apt/sources.list.d/bobine.list
echo "deb [signed-by=/etc/apt/keyrings/bobine.gpg] https://apt.bobine.fit/ stable main" | sudo tee /etc/apt/sources.list.d/bobine.list
Accès anticipé (Canal Bêta) : Pour recevoir les versions préliminaires roulantes en cours de test, remplacez simplement stable par beta dans la commande ci-dessus. Le paquet s'installe par-dessus sans créer de doublon.
3.

Installation et mises à jour système

Mettez à jour vos listes de paquets puis installez Bobine. Les futures versions seront automatiquement proposées lors de vos sudo apt upgrade habituels :

Terminal (Bash)
sudo apt update && sudo apt install bobine
