Dépôt APT Officiel Bobine

Installez et maintenez Bobine à jour via le gestionnaire de paquets standard apt. Dépôt binaire signé cryptographiquement par GPG avec prise en charge native des canaux Stable et Bêta.

Dépôt Opérationnel (Edge CDN) Debian 12 / 13 & Ubuntu 22.04 / 24.04 Signature GPG RSA 4096 Architecture amd64
1

Importer la clé de signature GPG officielle

Enregistrez la clé publique du dépôt dans le trousseau sécurisé /etc/apt/keyrings/ pour valider l'intégrité cryptographique des paquets :

Terminal (Bash)
curl -fsSL https://apt.bobine.fit/bobine.gpg | sudo gpg --dearmor -o /etc/apt/keyrings/bobine.gpg
2

Ajouter le dépôt Bobine aux sources APT

Configurez la source APT correspondant à votre canal choisi (Stable) :

/etc/apt/sources.list.d/bobine.sources
sudo tee /etc/apt/sources.list.d/bobine.sources <<'EOF' Types: deb URIs: https://apt.bobine.fit/ Suites: stable Components: main Signed-By: /etc/apt/keyrings/bobine.gpg EOF
3

Mettre à jour les index et installer Bobine

Actualisez vos listes de paquets puis lancez l'installation. Toutes les dépendances (FFmpeg, Avahi) seront résolues automatiquement :

Terminal (Bash)
sudo apt update && sudo apt install bobine
