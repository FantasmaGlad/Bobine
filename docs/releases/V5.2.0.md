La version **5.2.0 « Ruby »** succède à **5.1.2**. Bobine ne contacte plus aucun service extérieur, hormis la recherche de mise à jour. Chaque route de l'API a sa commande `bobine`. Les grandes bibliothèques se parcourent page par page.

## Confidentialité et hors ligne
- **Zéro télémétrie** : seule la recherche de mise à jour sort de la machine.
- Polices embarquées ; le kiosque et les navigateurs n'appellent aucun service tiers. L'interface fonctionne entièrement sans Internet.

## Pilotage
- **Toute route de l'API a sa commande `bobine`**. `bobine media list --kind video` donne les identifiants, `bobine play video <id> --channel cable` lance la lecture.
- Référence des commandes et de l'API générée depuis le code : `docs/reference/`, [bobine.fit/fr/commandes](https://bobine.fit/fr/commandes) et [bobine.fit/fr/api](https://bobine.fit/fr/api).
- Erreurs de l'API sous une forme unique `{code, message}`, avec des statuts harmonisés (404, 409, 422).
- Réponses typées dans le schéma `/openapi.json`.

## Grandes bibliothèques
- Catalogue des médias paginé directement en base.
- Toutes les listes acceptent `limit` et `offset`, avec le total dans l'en-tête `X-Total-Count`. Côté ligne de commande : `--limit` et `--offset`.
- Le journal technique se lit depuis la fin du fichier, même s'il est volumineux.

## Réseau et fiabilité
- **Plusieurs Bobine sur un même réseau** : si `bobine.local` est déjà pris, Bobine se publie en `bobine-2.local` (jusqu'à `bobine-9.local`). Réglages affiche le nom retenu.
- Clés étrangères SQLite actives. Une programmation dont la cible est supprimée disparaît avec elle.
- Archives importées sous Windows : noms réservés (`CON`, `COM1`…) et flux alternés refusés.
- Renommer une playlist radio est de nouveau enregistré.

## Distribution
- Paquets `.deb`, `.rpm` et pacman assemblés par une seule étape commune.
- Le `.deb` amd64 est construit sur Ubuntu 24.04, sous le plancher glibc annoncé.
- Métadonnées DNF compressées en gzip pour les anciennes versions de dnf.

## Code
- Fonctions du serveur limitées à 80 lignes, fichiers de l'interface à 500 lignes, chacun avec une garde dans les tests.
- Pages de l'interface rangées par dossier de composants.
- Service Android découpé par responsabilité.
