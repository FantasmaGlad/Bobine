La version 3.0.1 fait suite à la sortie officielle multi-plateforme de la 3.0.0 avec un objectif clair : donner aux utilisateurs un accès anticipé et maîtrisé aux nouvelles fonctionnalités, sans jamais mettre en péril la stabilité de l'exploitation en salle. Cette version introduit le **canal de mise à jour Stable/Bêta**, un **dépôt APT officiel** (`apt.bobine.fit`) pour Debian/Ubuntu, et une série de corrections de fiabilité identifiées lors des premières installations réelles sur Windows, macOS et Linux.

## 2. Canal de Mise à Jour Stable / Bêta ("Programme Bobine Beta")

La fonctionnalité phare de cette version : un choix explicite entre deux canaux de mise à jour, modifiable à tout moment depuis **Réglages → Mises à jour logicielles**, sans jamais perdre ses vidéos, playlists ou réglages.

* **Stable (par défaut)** : suit exclusivement les releases officielles taguées (`Vx.y.z`), historique normal sur GitHub Releases. Structurellement incapable de recevoir une pre-release, même en cas de bug applicatif (l'API GitHub `/releases/latest` exclut nativement les pre-releases).
* **Bêta** : accès anticipé aux fonctionnalités en cours de développement, reconstruite et republiée automatiquement à **chaque nouveau commit sur `main`** — un unique tag mobile `beta`, jamais d'accumulation de versions intermédiaires sur la page Releases publique.
* **Notification de mise à jour intégrée** : bouton "Vérifier les mises à jour" dans Réglages, avec notes de version consultables et téléchargement en un clic (ou mise à jour en place sur l'appliance headless).
* **Retour arrière (downgrade) sans perte de données** : repasser de Bêta à Stable — ou vers n'importe quelle version antérieure — à tout moment depuis Réglages, sans toucher aux vidéos, playlists ni réglages.

## 3. Ouverture Simultanée Tableau de Bord + Kiosque Câblé

À l'installation sur **Windows, macOS et Linux Bureau**, l'application ouvre désormais automatiquement **deux fenêtres** : le tableau de bord d'administration *et* le kiosque câblé (le canal de diffusion principal), à l'image du comportement déjà en place sur l'appliance headless via systemd. L'utilisateur ferme simplement l'une des deux fenêtres si un seul usage l'intéresse.

## 4. URLs Réseau Dynamiques dans les Réglages

La section **Documentation** de Réglages affiche désormais, pour chaque page publique (Cinéma, Radio, Télécommande…), son URL complète sur le réseau local calculée dynamiquement à partir de l'adresse IP de la machine (ex. `http://192.168.1.42:8000/radio`) — en complément du nom mDNS `bobine.local`, utile quand la découverte par nom échoue.

## 5. Dépôt APT Officiel (apt.bobine.fit)

Debian, Ubuntu et Linux Mint disposent désormais d'un vrai dépôt APT signé GPG, publié automatiquement par la CI en parallèle de chaque release Stable et Bêta :

```bash
curl -fsSL https://apt.bobine.fit/bobine.gpg | sudo gpg --dearmor -o /usr/share/keyrings/bobine.gpg
echo "deb [signed-by=/usr/share/keyrings/bobine.gpg] https://apt.bobine.fit stable main" | sudo tee /etc/apt/sources.list.d/bobine.list
sudo apt update && sudo apt install bobine
```

Les mises à jour suivent alors le cycle `apt upgrade` standard, canal Stable ou Bêta selon la ligne `sources.list` choisie.

## 6. Assistant Tauri : Scan Réseau Complet & Import de Clé SSH

L'assistant graphique (`assistant/`) affiche désormais **tous les appareils qui répondent sur le réseau local** — nom d'hôte (résolution DNS inverse), adresse IP, système d'exploitation estimé et ports ouverts — et non plus uniquement les cibles Debian/Bobine avec le port SSH ouvert. Un utilisateur préparant un déploiement headless voit ainsi le réseau tel qu'il est réellement (routeur, imprimante, autres postes...), ce qui l'aide à identifier sa borne avec certitude plutôt que de faire face à une liste tronquée pouvant laisser croire à un scan incomplet ou cassé.

En complément du mot de passe et du repli automatique sur l'agent SSH / les clés usuelles de `~/.ssh/`, un bouton **« Importer une clé SSH »** ouvre un sélecteur de fichier natif pour choisir explicitement une clé privée locale (utile pour une clé stockée à un emplacement ou sous un nom non standard).

## 7. Corrections de Fiabilité (retours d'installations réelles)

* **macOS** : `CFBundleVersion`/`CFBundleShortVersionString` reflètent enfin la vraie version buildée (auparavant figés à "3.0.0" quelle que soit la version réelle). Documentation Gatekeeper précisée : le message réellement rencontré est *"fichier endommagé"* (pas "développeur non identifié"), sans option "Ouvrir quand même" — la solution est `xattr -cr /Applications/Bobine.app`.
* **Linux Bureau (.deb)** : nom de fichier de la release Bêta corrigé (`bobine_beta_amd64.deb`, underscore et non tiret) — le lien de téléchargement Bêta renvoyait une 404.
* **Assistant Tauri** : hiérarchie des versions corrigée — un assistant lancé depuis un build Bêta ne se voit plus proposer, à tort, une "mise à jour" vers une Stable en réalité plus ancienne (l'assistant embarque désormais sa version et son commit à la compilation).
* **CI/CD** : la release Bêta ne prenait plus le rythme de `main` (dépendait d'un déclenchement manuel oublié) — elle se republie désormais automatiquement à chaque push, tout comme le dépôt APT.
* **Thème** : le thème clair devient le thème par défaut au premier lancement.

## 8. Nettoyage du Dépôt

Suppression des fichiers obsolètes ou spécifiques à un contexte web qui n'avaient pas leur place dans le dépôt applicatif (`patch.md`, `llms.txt`, README boilerplate `create-next-app` du frontend) — sans incidence sur le fonctionnement de l'application.
