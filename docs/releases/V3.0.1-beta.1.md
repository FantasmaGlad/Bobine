# Bobine V3.0.1-beta.1

Pre-release — accès anticipé aux fonctionnalités en cours de développement. Une version stable équivalente ou plus récente la remplacera automatiquement pour tous les utilisateurs, y compris ceux qui suivent le canal Bêta.

Réservée aux utilisateurs ayant explicitement activé le canal Bêta ("Programme Bobine Beta") dans Réglages → Mises à jour, dans l'assistant d'installation Tauri, ou via `install.sh --channel=beta`.

## Nouveautés depuis V3.0.0 (stable)

- **Canal de mise à jour Stable / Bêta** : nouveau réglage "Programme Bobine Beta" dans Réglages → Mises à jour, permettant de basculer entre le canal Stable (par défaut) et le canal Bêta (accès anticipé), avec retour possible au canal Stable à tout moment sans perte de données.
- `install.sh --channel=stable|beta` : sélection du canal dès l'installation en ligne de commande, avec persistance pour les réinstallations idempotentes.
- Assistant d'installation Tauri : même choix de canal dans l'étape "Options" du wizard, relayé à `install.sh` lors du déploiement distant.
- `GET /api/updates/check` respecte désormais le canal choisi : le canal Stable ne voit jamais de pre-release (limitation structurelle de l'API GitHub `/releases/latest`), le canal Bêta reçoit la dernière release publiée, stable ou non.
- Comparaison de version consciente des pre-releases (`3.0.1-beta.2` reconnu comme postérieur à `3.0.1-beta.1`, et toute version stable toujours reconnue comme postérieure à une bêta de même base).
- Mise à jour automatique de l'appliance headless (bouton "Mettre à jour") : bascule désormais sur le tag Git ciblé (`git checkout`) plutôt qu'un simple `git pull`, ce qui permet un vrai retour en arrière (downgrade) vers une version antérieure.
- Notification proactive de mise à jour disponible : vérification automatique (sans clic) dans Réglages, item de menu dédié dans BobineTray (zone de notification Windows/macOS/Linux), et bannière dans l'assistant Tauri — un seul bouton pour télécharger.
- Installation câblée et à distance : ouverture automatique du kiosque câblé en plus du tableau de bord d'administration à l'issue de l'installation (BobineTray et assistant Tauri), et documentation des URLs des écrans (kiosque, cinéma, coach, radio) avec IP locale dynamique dans Réglages → Documentation.
- CI : publication des releases GitHub consciente des pre-releases (`prerelease: true` sur les tags `-beta.`/`-rc.`/`-alpha.`), `install.sh` désormais attaché aux artefacts de chaque release, et source de vérité unique du numéro de version (fichier `VERSION`).

## Notes

- Aucune migration de données requise.
- Le canal Bêta peut inclure des fonctionnalités incomplètes ou instables — à réserver aux installations de test ou aux utilisateurs volontaires pour les retours anticipés.
