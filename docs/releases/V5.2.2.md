# Bobine V5.2.2 — bobine.local sous Android, validation et fichiers préservés

La version **5.2.2** succède à **5.2.0** et la corrige. Elle n'a pas fait l'objet d'une validation complète sur matériel réel.

## Android
- **`bobine.local` est de nouveau publié** sous Android et Android TV : la 5.2.0 ne l'annonçait plus sur le réseau.
- Les paramètres de requête (tri, période, type de média) sont validés comme sur les autres plateformes ; une valeur inconnue est refusée au lieu de provoquer une erreur.
- La suite de tests du serveur passe en entier sous le profil Android à chaque modification.

## Fiabilité
- Une normalisation vidéo en échec conserve le fichier d'origine.
- Nom réseau : un échec à l'ouverture du réseau est signalé dans Réglages puis réessayé ; l'annonce reste unique après un changement d'adresse.
- Miniature trop grande, archive au nom invalide, pagination hors bornes : refus clair (422) au lieu d'une erreur du serveur.
- L'occupation disque affichée compte tous les dossiers de données.

## Pilotage
- `bobine audio set` règle le fond d'un cours ; `bobine radio-library set` règle l'artiste de l'album, les numéros de piste et de disque et les étiquettes.
- `bobine library list --release`, `bobine storage browse --offset --show-hidden --media-only`.
- Les erreurs de validation s'affichent une seule fois, en clair.

## Interface
- Boutons à icône nommés pour les lecteurs d'écran ; le libellé des onglets du planning suit le canal affiché.
- Textes restés en français dans l'interface anglaise traduits.

## Distribution
- Les paquets Linux livrent et rafraîchissent le trousseau de signature ; `install.ps1` accepte plusieurs sous-clés.
